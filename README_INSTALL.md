# TEVIEW installation choices

**Fastest with Python (offline):** install the included `.whl` file; see `docs/INSTALL_PIP.md`.

**Windows without Python:** use the signed-or-unsigned Windows build produced by `.github/workflows/windows-exe.yml` after a successful run. The source ZIP alone is not an EXE.

**No installation at all:** open `OPEN_DEMO.html` for recorded playback (does not recompute physics).

**Scientific boundary:** these are simplified simulations. Do not use for safety-critical design or validated experimental predictions without checking models against external data.
